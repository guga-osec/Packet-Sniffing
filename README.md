# Packet-Sniffing
Capturing and Analysing Network Packets

This code was made entirely in Windows, I tested it in Linux and some errors occurred, I still need to better it so It can work in both OS.
Anyway, here I let a brief explanation about the code itself.

For this Project I used the following python libraries:
* scapy - for the analyse of the network
* threading - used to run tasks concurrently
* customtkinter - used for the UI
* tkinter - used for the UI
* queue - used to store , organize and distribute tasks
* time - to delay some parts of the code

## Core.py
The core.py as the name suggests is the principal part of the other 3, it provides the content to show in a CLI or in the GUI code.
